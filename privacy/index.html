사진은 기기 밖으로 나가지 않아요

시행일 2026년 10월 15일. 해담 iPhone 앱과 이 웹사이트(haedam.jiun.dev)에 적용돼요.

모으는 정보

해담은 회원가입이 없고, 이름·이메일·기기 식별자 같은 개인정보를 모으지 않아요. 광고, 분석 도구, 추적 기능도 넣지 않았어요.

사진과 분석

  • 사진 분석(밝기, 색, 장면 인식)과 보정은 모두 iPhone 안에서 이뤄져요. 사진을 서버로 보내지 않아요.
  • 사진에 담긴 촬영 시간과 위치(GPS)는 해의 높이를 계산해 룩을 추천하는 데만 기기 안에서 써요.
  • 공유할 사진을 만들 때는 위치와 촬영 정보를 지우는 설정이 기본으로 켜져 있어요.
  • 내 스타일에는 작은 미리보기와 보정 수치만 기기 안에 저장해요.

앱이 요청하는 권한

  • 사진 보관함: 오늘 찍은 사진으로 덤프를 만들고, 보정한 사진을 저장하고, 저장한 사진의 레시피를 다시 열 때 써요. 일부 사진만 허용해도 동작해요.
  • 카메라: 촬영 탭에서 룩을 실시간으로 미리 보며 찍을 때만 써요.

네트워크 사용

  • 앱은 커뮤니티 레시피 목록(feed.json)을 이 웹사이트에서 받아와요. 이 요청에는 사진이나 개인정보가 담기지 않아요.
  • 레시피 링크는 보정 수치를 주소의 # 뒷부분에 담아요. 이 부분은 브라우저가 서버로 보내지 않아서, 링크를 열어도 수치가 서버에 남지 않아요.
  • 이 웹사이트는 GitHub Pages로 운영돼요. 다른 웹사이트와 마찬가지로 GitHub가 접속 기록(IP 주소 등)을 보안 목적으로 남길 수 있어요. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.
